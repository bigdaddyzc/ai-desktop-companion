# P2 真机补验清单

这些功能代码和自动化测试都在，缺的是在你电脑上真跑一遍。按顺序做，每项 5–30 分钟。
做完一项就把「结果」写上（通过 / 不通过 + 一句现象），我据此更新 [能力清单](capabilities.md)。验不过的进下一轮，不在本轮顺手加功能。

开始前：关掉芯伴 → 拉最新代码 → `npm run build` → 双击 `启动芯伴.cmd`。出问题时先看面板「伙伴与设备 → 运行状况」，点「打开日志目录」把当天的 `app-*.log` 发我（里面没有对话内容和 Key）。

## 需要你拍板的

- **健康信息要不要记**：人设规定「健康细节不记」，所以你说「记住我对花生过敏」它会拒绝；但代码没拦，偶尔仍会记。二选一：① 代码也拦（更私密）；② 放开「过敏、忌口」这类对陪伴有用的，仍不记病史用药。
- **替你确认是否重新打开**：第 2 项验过后由你决定。
